# Матчасть: правила выбора плана и ракурса (для промта «Шотов»)

Собрано отдельным агентом 21.11.2026 через web_fetch. Источник правил в проде —
раздел «Ракурсы и показ действия в сцене» в
`templates/node_groups/plan_cinema/scenes_to_frames_plan_ru.md`.

Формат: **условие → что ставить → почему** [S#].

## 1. Крупности

- Мир важнее человека → EWS / extreme wide: фигура почти неразличима → масштаб и одиночество; первый или последний кадр сцены [S4][S20].
- Нужна география + движение целиком → LS / wide: фигура в рост, среда читается → широкий кадр вмещает движение без рефрейма (драки, танцы, погони) [S20].
- Жест + поза + среда → MLS / «американский» (до колен) → видно и тело, и контекст [S4][S20].
- Разговор с жестами, двое в кадре → MS (по пояс) → компромисс «лицо и руки», базовый кадр диалога [S3][S20].
- Лицо + руки, стандарт ТВ-диалога → MCU (от груди) → эмоция читается, партнёр ещё в кадре плечом [S5][S20].
- Эмоция, интимность, ввод героя → CU: голова занимает кадр → внимание к человеку, а не к месту [S5].
- Улика, напряжение, деталь → ECU / detail: глаз, кольцо, цифра → максимум детали, контекста нет [S4][S20].
- Предмет или рука внутри уже снятого действия → insert → акцент на детали, которой не видно в общем плане [S13].
- Крупность мерить по шкале самого материала, а не по сантиметрам [S20].
- Крупный план на широком объективе → не ставить без мотива → лицо «плывёт» [S5].
- Много CU подряд → брак → зритель теряет, где он [S5].
- Нарастание/сброс в диалоге → lean-in (MS→CU к финалу) и lean-out (CU→шире на развязке) [S5].

## 2. Ракурсы и высоты

- Нейтрально → eye level → база диалога, почти без эффекта [S6].
- Доминирование, угроза → low angle → фигура читается сильной и властной [S6][S8][S20].
- Слабость, зависимость → high angle → человек мал и уязвим [S6][S20].
- Связь людей с местом → bird's eye → как персонажи соотносятся с пространством [S6][S20].
- Взгляд «ребёнка/животного» → worm's eye → камера у земли вверх [S6].
- Мир сломан, хаос → dutch / canted → наклон горизонта = неустойчивость [S7][S20].
- Dutch без причины → клише: «наклоняют, но не знают зачем» (Эберт) [S7]. В нашей цепочке dutch не входит в канон ракурсов.
- Разговор через плечо → OTS: камера над плечом партнёра → привязка к точке зрения слушающего; плечо на своей стороне оси [S3][S4].
- Взгляд персонажа → POV только в паре «кто смотрит → что видит» [S20].
- Разрыв и дистанция → фронтал (0°): пара фронтальных планов разводит людей [S21].
- 3/4 → рабочий дефолт диалога: и лицо, и направление взгляда [S1][S19].
- Профиль → крайняя точка оси; пара профилей = reverse shot, стороны не путать [S1][S17].
- Высота камеры = иерархия: разная высота для разных персонажей читается как «кому здесь место» [S20].

## 3. Монтаж и склейки

- Двое в сцене → камера только на одной стороне оси; переход = crossing the line / reverse cut [S1][S22].
- Ось через движение → вышел кадром влево — вошёл справа [S1][S14].
- Ось через транспорт → выехал справа — входит слева [S1].
- Ось через взгляд → eyeline match: смотрит влево — объект за кадром справа [S21].
- Перейти ось надо → буферный кадр по оси, дуга камерой или переустановочный план [S1][S22].
- Две склейки одного объекта → угол ≥30° или фокусное ≥20 мм разницы; меньше — jump cut [S2].
- «Прыжок» по крупности без смены угла → axial cut (камера вдоль оси) держит непрерывность [S15].
- Jump cut → только как приём (время, клип, распад сознания); в нарративе без мотива — брак [S16][S21].
- Склейка внутри движения → cut on action (рука на ручке — дверь открывается в следующем кадре) [S14].
- Кадр «про что-то ещё» → cutaway: реакция, среда, объект не из master [S12].
- Кадр «то же, но ближе» → insert (этим и отличается от cutaway) [S13].
- Пара «кто → на кого» → shot/reverse shot, частный случай eyeline match [S17][S21].

## 4. Покрытие сцены

- Любая сцена действия → сначала master целиком, потом остальное → coverage обязан с ним совпадать [S10][S11].
- Master — скелет монтажа: остальные кадры вставляются внутрь [S3][S11].
- Пара call/answer → одинаковое фокусное и дистанция фокуса, иначе персонажи «прыгают» по масштабу [S11].
- Чтение географии → establishing (где) → medium (кто с кем) → CU (что внутри) → reestablishing при путанице [S18][S20][S21].
- Вход в помещение → склейка на ручке/шаге + сохранённое экранное направление, иначе «телепорт» [S14][S9].
- Жест или предмет → сначала MS с контекстом, потом insert детали [S13].
- Бег, драка, танец → широкий кадр держит движение без рефрейма [S20].
- Масштаб как смысл → EWS в начале или конце сцены [S20].

## 5. Диалог и монолог

- Двое → ось между ними, стороны фиксированы на всю сцену [S1].
- Смена крупности → вместе с углом; одна крупность без угла = jump cut [S2][S16].
- Реплика → CU/MCU на говорящем; реакция → MCU/MS на слушающем [S12][S21].
- Партнёр в кадре → плечо на своей стороне оси; ошибка ломает сцену [S4][S1].
- Финал сцены → lean-in; разрядка после пика → lean-out [S5].
- Монолог → один план либо смена угла/axial cut; «то же, но чуть ближе» нельзя [S2][S15].
- Взгляд в камеру → только осознанный слом четвёртой стены [S23].
- Смена стороны персонажа между кадрами → брак: читается как «поменялись местами» [S1][S9].

## 6. Частый брак

- Угол <30° между кадрами → jump cut [S2].
- Смена крупности без смены угла → тот же jump cut [S2].
- Пересечённая ось → reverse cut [S1][S22].
- Направление движения не совпало → «телепорт» [S9].
- Взгляд не совпал по направлению/высоте → читается, что смотрит на другое [S21].
- Взгляд в камеру без мотива → выпадение из фикции [S23].
- Крупные планы без контекста подряд → зритель потерял место [S5].
- Dutch без системы → «наклонили, потому что красиво» [S7].
- Insert не совпал по свету/положению → ляп continuity [S13].
- Мастер не снят → сцену нечем спасать в монтаже [S10][S11].

## 7. Сцены действия

- Драка/перестрелка → сначала широкий master для географии, потом крупности; ось критична [S1][S10].
- Удар/бросок/падение → cut on action, а не между действиями (Куросава) [S14].
- Много участников → coverage сверх обычного: reaction, POV, средние и общие [S11].
- Погоня → экранное направление: выехал справа — вошёл слева [S1][S9].
- Погоня, нужен обзор → широкий/верхний кадр + короткие insert на детали [S6][S13].
- Работа руками → MS на позу и руки + insert на контакт [S13][S20].
- Вход в помещение → снаружи на дверь, склейка на ручке/шаге, внутри обратный план с той же стороны оси [S14][S1].
- Через плечо → OTS на обоих, плечи на своих сторонах, одинаковое фокусное [S4][S11].
- Теснота → не уходить на 3/4 «из-за некуда ставить камеру» — перенос оси не спрячется [S1][S22].
- Узкое пространство → широкий объектив и низкая/высокая точка вместо смены крупности [S20][S1].
