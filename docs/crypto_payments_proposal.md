> **Статус документа:** На согласовании с владельцем продукта  
> **Дата составления:** 16 ноября 2026 г.  
> **Цель:** Подключение приёма криптовалютных платежей (USDT, TON, BTC, ETH) для автоматического пополнения баланса кредитов в студии  
> **Архитектурный контекст:** Платформа уже имеет готовый транзакционный леджер `credit_ledger.topup()` и интерфейс баланса в `payments-panel.tsx`. Требуется подключить платёжный шлюз.

## 1. Варианты реализации: сравнение и выбор

Для интеграции криптоплатежей существует три принципиально разных подхода. Ниже приведено детальное сравнение:

```mermaid
flowchart TD
    User["Пользователь студии"] -->|Выбирает пакет кредитов| WebUI["Веб-интерфейс студии"]
    WebUI -->|Запрос инвойса| Backend["FastAPI Бэкенд"]
    
    subgraph OPTIONS["Варианты процессинга"]
        Backend -->|Вариант 1 (Рекомендуется)| Cryptomus["Cryptomus / CryptoCloud Gateway"]
        Backend -->|Вариант 2| CryptoBot["Telegram Crypto Pay API"]
        Backend -->|Вариант 3| DirectNode["Собственный On-Chain монитор"]
    end
    
    Cryptomus -->|Webhook с HMAC-подписью| WebhookHandler["Обработчик вебхука"]
    CryptoBot -->|Webhook| WebhookHandler
    DirectNode -->|Сканирование блоков| WebhookHandler
    
    WebhookHandler -->|credit_ledger.topup()| Ledger["Транзакционный леджер БД"]
    Ledger -->|Мгновенное зачисление| UserBalance["Баланс кредитов пользователя"]
    Cryptomus -->|Автовывод средств| OwnerWallet["Личный кошелёк владельца (USDT)"]
```

### Сравнительная таблица подходов:

| Критерий | Вариант 1: Cryptomus / CryptoCloud (Шлюз) ⭐ **Рекомендуется** | Вариант 2: Telegram Crypto Pay (@CryptoBot) | Вариант 3: Собственный On-Chain процессинг (нода) |
| :--- | :--- | :--- | :--- |
| **Поддерживаемые монеты** | USDT (TRC20, TON, BEP20, Polygon, ERC20), TON, BTC, ETH, SOL, LTC, TRX (все популярные) | USDT (TRC20, TON), TON, BTC, ETH, NOT | Только те, под которые написан мониторинг (обычно только USDT TRC20) |
| **Комиссия сервиса** | **0.4% – 1.9%** (минимальная по рынку) | **1% – 3%** | 0% сервису, но высокие сетевые комиссии за сбор средств (газ) |
| **Удобство для пользователя** | Превосходное: готовая форма с QR-кодом, таймером, выбором сети с дешёвыми комиссиями ($0.2–$1) | Очень высокое для пользователей Telegram (оплата в 2 клика) | Среднее: пользователь сам вводит адрес и ждёт подтверждений сети |
| **Вывод средств владельцу** | **Автоматический (Auto-payout):** средства сразу или по расписанию улетают на личный холодный кошелёк владельца | Ручной или автовывод из бота на кошелёк владельца | Деньги уже на кошельках, но их нужно вручную/скриптом собирать (sweep) |
| **Сложность разработки** | **Низкая (2–3 дня):** стандартный REST API + вебхук с проверкой подписи | **Низкая (2–3 дня):** готовый API бот-платформы | **Экстремально высокая (2–4 недели):** мониторинг блоков, реорги, комиссии за газ на каждом адресе |
| **Требование к юрлицу** | Не требуется (аккаунт мерчанта физлица) | Не требуется | Не требуется |

## 2. Что лучше выбрать и почему?

### 🥇 Основной выбор: **Cryptomus** (или CryptoCloud как альтернатива)
**Почему это лучший выбор:**
1. **Поддержка USDT в сетях TRC-20, TON, BEP-20 и Polygon:** Пользователи не хотят платить $15–$25 комиссии сети Ethereum. В сетях TRC20, TON и Polygon комиссия за перевод составляет всего $0.2–$1.2, что критично для микроплатежей ($10–$50).
2. **Решение проблемы «Свипа» (Sweep):** Если делать свои кошельки (Вариант 3), то чтобы собрать USDT с 50 кошельков пользователей на один кошелёк владельца, придётся на каждый из 50 кошельков сначала закинуть TRX/BNB на оплату газа! Это разорительно по комиссиям и тяжело в поддержке. Шлюз Cryptomus берёт это на себя.
3. **Безопасный автовывод на кошелёк владельца:** Владелец один раз указывает свой личный адрес USDT TRC20/TON (в Trust Wallet, Ledger или на бирже), и шлюз автоматически пересылает туда чистую выручку.
4. **Конвертация волатильных монет:** Если пользователь заплатит в BTC, ETH или TON, сервис может автоматически конвертировать их в стабильный USDT, защищая студию от скачков курсов.

### 🥈 Дополнительный параллельный вариант: **Telegram Crypto Pay (@CryptoBot)**
Если целевая аудитория студии активно пользуется Telegram — этот вариант можно подключить вторым шагом. Для пользователей с кошельками в Telegram оплата происходит буквально за 5 секунд без перехода на внешние сайты.

## 3. Какие данные и действия потребуются от владельца?

Для запуска оплаты владельцу нужно предоставить всего **4 пункта**:

### 1. Регистрация мерчант-аккаунта:
- Зарегистрироваться на [cryptomus.com](https://cryptomus.com/) (или cryptocloud.plus). Занимает 5 минут, юрлицо не требуется.
- Создать проект/мерчант (название: «Video Studio»).

### 2. Ключи интеграции (API Keys):
Из личного кабинета мерчанта скопировать:
- `MERCHANT_ID` — уникальный идентификатор мерчанта;
- `PAYMENT_API_KEY` — ключ для выставления счетов;
- `PAYMENT_WEBHOOK_KEY` — секретный ключ для проверки подлинности уведомлений об оплате.

### 3. Личный адрес кошелька для автовывода (Payout Address):
- Адрес личного кошелька владельца для получения денег (например, `USDT TRC-20` или `USDT TON`).
- В настройках Cryptomus включить тумблер *Auto-payout* (автоматический вывод при накоплении от $50 или раз в сутки).

### 4. Утверждение тарифной сетки пакетов:
Студия тарифицирует операции в **кредитах**. Нужно утвердить соотношение курса:
- **Базовый курс:** $1 = 100 кредитов (себестоимость минуты видео/озвучки известна).
- **Рекомендуемые пакеты для пополнения:**

| Пакет | Стоимость | Количество кредитов | Бонус | Примерный объём работы |
| :--- | :---: | :---: | :---: | :--- |
| **Старт** | **$10** | 1 000 кр. | — | 1–2 коротких ролика под ключ |
| **Оптимум** | **$25** | 2 750 кр. | **+10%** (250 кр.) | 3–5 полноценных роликов |
| **Про** | **$50** | 6 000 кр. | **+20%** (1 000 кр.) | 7–10 роликов |
| **Студия** | **$100** | 13 000 кр. | **+30%** (3 000 кр.) | Пакетное производство роликов |
| **Своя сумма** | от $5 | по базовому курсу | — | Любая гибкая сумма |

*Примечание по комиссии:* Рекомендуется комиссию шлюза (1–2%) брать на сторону студии, чтобы пользователь платил ровно круглую сумму (например, ровно $10 или $25).

## 4. Архитектурная интеграция в проект

### Бэкенд (FastAPI + SQLAlchemy + PostgreSQL/SQLite):
1. **Новая таблица `crypto_invoices`:**
   - `id` (UUID) — внутренний номер счёта.
   - `tenant_id` — ID пользователя/арендатора студии.
   - `amount_usd` — сумма в долларах.
   - `credits_to_add` — сколько кредитов будет начислено.
   - `status` — `pending` | `paid` | `expired` | `failed`.
   - `provider` — `"cryptomus"`.
   - `provider_order_id` — ID заказа на стороне шлюза.
   - `pay_url` — ссылка на форму оплаты для клиента.
   - `created_at`, `paid_at`.

2. **Эндпоинты в `app/web/routers/billing.py`:**
   - `POST /api/billing/crypto/invoices` — создание инвойса, обращение к Cryptomus API, возврат `pay_url`.
   - `POST /api/billing/crypto/webhook` — приём вебхука от Cryptomus, криптографическая валидация подписи HMAC-SHA256. При успешной оплате:
     ```python
     await credit_ledger.topup(
         session=session,
         tenant_id=invoice.tenant_id,
         amount_micro=invoice.credits_to_add * 1_000_000,
         memo=f"Крипто-пополнение #{invoice.id} (${invoice.amount_usd})",
     )
     ```
   - `GET /api/billing/crypto/invoices/{id}` — проверка статуса для фронтенда.

### Фронтенд (React 19 / Next.js):
В компоненте [payments-panel.tsx](file:///C:/Users/EternalFlow/Documents/OpenCode/general/video-pipeline-web/web/src/components/panels/left-bottom/payments-panel.tsx) сейчас кнопка «Пополнить» отключена заглушкой (*«Пополнение отключено: студия пока не принимает платежи»*).
- Мы активируем кнопку «Пополнить».
- При нажатии открывается диалоговое окно пополнения:
  - Выбор пакета ($10, $25, $50, $100 или своя сумма).
  - Отображение бонуса и эквивалента в кредитах.
  - Кнопка **«Оплатить криптовалютой»** (открывает защищённое окно Cryptomus или перенаправляет на оплату).
  - После оплаты окно фиксирует успешный платёж, и баланс кредитов в шапке обновляется в реальном времени без перезагрузки.

## Резюме

- **Безопасно:** студия не хранит чужие приватные ключи и не рискует средствами.
- **Деньги сразу у владельца:** выручка автоматически пересылается на личный криптокошелёк владельца.
- **Минимальные комиссии:** пользователи могут платить в сетях USDT TON/TRC20 с комиссией сети менее $1.
- **Готовая инфраструктура:** существующий движок `credit_ledger` уже готов мгновенно зачислять баланс по факту оплаты.
